# v0.3.0 发布验证

日期：2026-09-10。本记录针对本次发布前工作区，不以历史日志代替当前结果。

## 构建与回归

使用 MSVC、Ninja、Release 构建，示例与测试均开启。LumaText 使用发布工作流固定的预编译包并核对 SHA256，避免本地源码依赖与线上发布版本不一致。

| 项目 | 本次结果 |
| --- | --- |
| 全量构建 | 成功，无 C++ 编译警告；README 示例编译及 API 命名检查通过 |
| visual | ALL PASS，包含 HostCycle 的 12 轮生命周期、外壳合成、圆角和焦点相关断言 |
| anim | ALL PASS |
| api | 退出码 0 |
| perf | 退出码 0；1280×800，300 帧，平均 1.588 ms，最差 1.872 ms |
| perf 分位数 | P50 1.563 / P95 1.758 / P99 1.827 ms；≥8 ms 为 0/300 |
| Table Draw 分配 | DirectWrite 与 LumaText 场景均为零 C++ 堆分配；Prepare 阶段不包含在该结论内 |
| Gallery | 当前构建启动、导出首页并正常退出；图像检查通过，不等同于完整实机交互验收 |
| 发布隐私检查器 | 干净样本放行；ASCII/UTF-16 用户路径及令牌样本均正确阻止 |

性能数据衡量 CPU 墙钟提交耗时，不包含完整 GPU 完成时间和窗口交互延迟。本轮结果不能证明历史偶发尖峰已永久消除。

本地日志位于 `build/release-{build,visual,anim,api,perf}.log`，属于忽略的构建产物，不纳入源码或 Release 附件。

## 公开内容检查

- 维护脚本改用脚本所在仓库定位路径，移除个人用户目录。
- 文档中的业务专属页面描述泛化，修正当前快照中指向缺失优化方案的链接。
- 检查待提交文件中的个人目录、邮箱、常见令牌及私钥标识，未发现匹配；二进制资源另检查 UTF-16 字符串。模式扫描不等同于穷尽所有敏感信息。
- 四张优化示例图经过人工图像检查，内容为 Gallery 示例数据，无个人桌面、账户或私人文档画面。
- 新提交与新标签使用 GitHub noreply 身份；保留公开仓库账号与许可证归属。
- 本地静态库检查发现构建目录路径，因此不上传本机 SDK；正式附件由 GitHub 构建，上传前执行 `tools/audit_release.py` 扫描包内路径与常见凭据标记，失败则阻止发布。
- 已公开历史中的私人邮箱和旧路径未通过本次普通提交删除；历史重写需要单独协调，不能声称历史数据已清除。
